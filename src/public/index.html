Instrucciones

Seleccione el tipo de procesamiento según el archivo Excel que desea cargar:

1. Descarga Solicitudes

Para procesar archivos Excel de solicitudes de la SIC.*Recordar haber eliminado las 6 primeras filas de cada excel.

2. Descarga Gaceta SIC

Para procesar archivos Excel de la Gaceta SIC. El sistema comienza a procesar desde la fila 10, columna B y extrae hipervínculos.

3. Descarga Individual

Para descargar información de un expediente específico ingresando su número. Compatible con formatos SD2022/0049537 o 01029150 para expedientes previos a Junio de 2016.

  1. Seleccione el tipo de procesamiento usando las pestañas.
  2. Para las pestañas 1 y 2: Arrastre o seleccione el archivo Excel (.xls, .xlsx o .xlsm).
  3. Para la pestaña 3: Ingrese el número de expediente que desea consultar.
  4. Haga clic en "Procesar" para iniciar el proceso correspondiente.
  5. Espere a que el proceso termine. No cierre la ventana.
  6. Una vez completado, podrá revisar los detalles del procesamiento.
